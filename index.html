Auto-Launch Required

This project needs a local server

You opened index.html directly (file://). Browsers block ES modules and .bat execution for security — so index.html cannot auto-build and auto-run the server by itself. This is a browser sandbox limit, not a bug.

I’ve wired index.html to auto-detect and auto-redirect when the server is running, and to give you one-click launch helpers when it’s not:

Windows: double-click start.bat — now fixed for double-click
Mac/Linux: bash start.sh or npm run launch
Manual: npm install && npm run dev → http://127.0.0.1:5173
▶️ Open start.bat

Direct auto-execution of start.bat from HTML is blocked by all modern browsers (security sandbox). If it were allowed, any website could run code on your PC. The closest we can do: this page auto-redirects to localhost:5173 the moment you start the server — just keep this tab open and double-click start.bat.
